## 프로젝트 한 줄 설명

교내 분리수거장 상단의 카메라로 버리는 물품과 투입 위치를 탐지하고, 잘못된 분리배출을 발견하면 2초 이내에 화면과 알림음으로 알려 주는 시스템이다.

## 초기 프로젝트 범위

첫 번째 파일럿에서는 교내 분리수거장 한 곳과 다음 네 가지 분류만 다룬다.

1. 투명 페트병
2. 캔
3. 종이류
4. 일반 쓰레기

프로젝트의 핵심은 YOLO 객체 탐지, 물체 추적, 쓰레기통 ROI 판정 및 분리배출 규칙 비교이다. 색상 히스토그램과 윤곽 분석은 보조 특징으로만 사용한다.

## 데이터 처리 흐름

`카메라 입력 → 물품 탐지 → 물체 추적 → 투입된 쓰레기통 ROI 확인 → 분리배출 규칙 비교 → 즉시 피드백 → 익명 통계 저장`

## 파일럿 목표

아래 수치는 이미 달성한 결과가 아니라 파일럿에서 검증할 목표값이다.

| 지표 | 목표 |
|---|---:|
| 물품 탐지 Precision | 90% 이상 |
| 물품 탐지 Recall | 85% 이상 |
| mAP@0.5 | 85% 이상 |
| 잘못된 투입 판정 정확도 | 85% 이상 |
| 피드백 지연 시간 | 2초 이내 |
| 잘못된 분리배출 건수 | 기준 기간 대비 30% 감소 |

## 개인정보 보호 원칙

카메라는 얼굴이 아닌 손, 물품, 투입구만 촬영하도록 시야를 제한한다. 원본 영상은 저장하지 않고 추론 직후 폐기하며, 시간대별 물품 수와 오류 건수 같은 익명 통계만 보관한다. 실제 설치 전에는 학교 담당 부서의 승인을 받고 안내문을 게시한다.
